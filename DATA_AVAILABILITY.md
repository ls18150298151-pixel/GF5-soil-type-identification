# Data and code availability

The soil sample coordinates and soil-type labels used in the study were provided by Yunnan Daoshi Geographic Information System Engineering Co., Ltd. The data are not publicly available. Access requires approval from the data provider. Requests should be directed to the corresponding author identified in the submitted manuscript, who coordinates with the provider. This process applies to the reference data and supplementary sample records, including identifiers, linked predictors, spatial folds and per-sample predictions.

The code package provides format specifications, the registered candidate settings and an invented example generator. It contains no study samples, study imagery, environmental rasters, fitted models, actual results or study fold files. The fictitious inputs generated by the demo do not represent Luxi County or real soil classes at the example locations.

Sources for GF-5 imagery and environmental datasets are described in the manuscript, Section 2.2. Obtain the relevant source products independently under their applicable access terms. Exact model reproduction also requires access to the original aligned inputs or the frozen working rasters feeding those inputs. Keep any authorized inputs and their derived outputs local.

The manuscript dated 18 November 2026 states that the analysis code is available from the corresponding author upon request.
